The premise 01 / 05

Less page noise.
More useful context.

Agents do not need to execute a web page to read it. actdown separates meaning from presentation and delivers content in a format designed for inspection, not execution.

01Reader over MCPGive your agent a reading tool, not a browser workload. The stdio server exposes seven tools for transcoding, conversion, rendering, and document review.
02Canonical outputStable text makes useful diffs. A defined AST, assigned block IDs, and an idempotent printer give people and agents one shared representation.
03Network boundariesFetching has limits. Private targets are refused by default, every redirect is checked, and the default socket stays pinned to the validated address.
04Visible provenanceKnow what changed. Conversion is intentionally lossy. Scripts and styles are removed, and conversion notes report detected legacy behavior and hidden markup.
05Small by designNo framework required. The TypeScript implementation has zero runtime dependencies. The Rust port shares byte-exact conformance fixtures and can run as WebAssembly.

The format 02 / 05

Markdown you know.
Structure an agent can use.

Prose stays Markdown. Fenced ad-* blocks add state, semantic structure, forms, and named actions. The host owns behavior. The document never supplies JavaScript.

AST is the contract
Canonical text and the JSON AST describe the same document.
Human review stays possible
A proposed state change or capability is visible in a text diff.
Capability, not code
Actions name host-granted operations. Hosts must validate their arguments.
Graceful by default
Unknown block types remain readable fenced Markdown.

Get started 03 / 05

From a URL to structured context.

Use the MCP reader, convert existing HTML through the CLI, or embed the library directly. Requires Node.js 20 or newer.

01 / Connect

Run the MCP server.

Start the packaged stdio server. No separate MCP wrapper is needed.

npx -y -p actdown actdown-mcp
02 / Read

Ask for a page.

The agent supplies a URL and a format. The result includes source, notes, and the converted document.

actdown_transcode
{
  "url": "https://example.com",
  "format": "canonical"
}

The boundary 04 / 05

Useful conversion.
Explicit trust.

Page content is untrusted.

actdown does not decide whether a page is honest. Converted text, including visible text, remains data. Agents must not treat it as instructions from the user or host. Hidden-markup filtering is best effort, not prompt-injection prevention.

A development preview.

The HTTP gateway is intended for controlled development. Public deployments need a TLS proxy, explicit access policy, and production hardening. Read the security boundaries before connecting an exposed service.
